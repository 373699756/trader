## 阅读顺序

1. 想知道怎么运行：先看根README，再看下载训练。
2. 想知道为什么推荐：看评分逻辑的流程、字段表和计算示例。
3. 想知道系统怎么工作：看工程设计的结构图、内存流和时间线。
4. 想知道是否完成：只查工程实施，区分代码、fixture、实测、收益和发布。
5. 想提出或复核问题：使用人工审查清单，不复制另一份进度。
