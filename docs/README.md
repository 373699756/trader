## 阅读顺序

1. 想知道怎么运行：先看根README，再看下载训练。
2. 想知道为什么推荐：先看评分逻辑的11层流程、评分与风险、收益验证；完整字段按需查附录。
3. 想知道系统怎么工作：先看工程设计的结构图、资源、时间线与降级；精确参数和诊断键按需查附录。
4. 想知道是否完成：只查工程实施，区分代码、fixture、实测、收益和发布。
5. 想提出或复核问题：使用人工审查清单，不复制另一份进度。
