## 状态与时间的阅读规则

- 阶段 `completed` 表示该批次范围完成；实现、回归、真实供应商实测、真实运行验收和发布授权分别判断。
- 十四层业务链路与Web展示行数不是同一概念；界面整理本身不改变业务合同。
- Tomorrow/D25 的运行、研究评价与正式冻结统一为15:00 first-wins；研究点时事实与日线工程代理仍分别留证。
  旧14:50工件与历史记录保留原身份，不改写为新口径；新训练和回放重新生成证据。
- 当前状态只由工程实施台账维护；其它文档只描述合同、工程映射或验收要求。

## 历史证据与工具记录

`reports/`保存特定时点的研究或门禁报告。阅读时核对报告日期、提交、策略、数据身份及验证场景；
旧PASS、已发布或旧预算数字只适用于原批次，不能证明当前Afuture通过。历史路径可能已退役，
不会为使旧报告看起来“当前有效”而改写原始证据。

`changelog/`及根目录Changelog保留为只读历史档案，其原索引措辞不再代表活动交付流程；
后续改动与证据只登记到工程实施台账，不新增或更新Changelog记录及索引。

`updatecodex`是开发工具安装命令记录，不是产品运行入口或依赖合同。
当前工具使用及资源边界见[仓库README](../README.md)，公开入口仍以pyproject.toml为准。
