# 荐股策略文档

版本：v2（活动 Tomorrow 模型由 `tomorrow_scoring_profile=v1|v2` 选择，默认 `v1`，运行身份由有效配置 SHA-256 生成）

引擎：`engine_review28_2026_07`

融合：`fusion_local68_deepseek32`

状态：活动策略契约；V2-only 工程与发布门禁已验收，正式 0.2.0 release 尚未声明

本文是候选、过滤、因子、评分、风险、DeepSeek、融合、动作、排名和策略验收的唯一
权威。产品、架构、时间线、发布、API、运维和工程路线以
[软件业务设计文档](software-business-design.md) 为准。策略用于研究，不构成投资建议，
不保证收益，不触发真实交易。

### 0.1 评分目标与证据原则

Today、Tomorrow、D25 及其后续所有评分计划的唯一业务目标，是提高对应持有周期内可重复、扣除交易成本、
相对同日可投资 A 股基准的风险约束净超额收益。推荐数量、命中率、平均原始涨幅、页面非空和模型分数
本身都不是优化目标，不能为了避免 0 只结果降低风险、动作或收益门槛。研究晋级必须同时检查净超额、
严重亏损、最大不利变动、换手、容量、集中度、Rank IC 和分组单调性；收益改善若以不可接受的尾部风险
或交易成本为代价，不得宣称评分更优。

每个新评分计划必须在读取评价区间收益前登记策略、持有期、训练代理锚点、生产预测锚点、成本后基准、主要收益指标、
尾部风险、换手/容量、样本外切分、统计功效、停止条件和生产权限。缺少任一项的工作只能标记为数据或
因子诊断，不能进入调权、模型选择、阈值修改或生产发布。历史 point-in-time 回放和工程实现都必须服务于
这个收益目标，但工程完成本身不构成收益改善证据。

生产数据就绪与收益证据必须分离。过去行情窗口只服务于明确登记的因子或模型输入；线上结算标签只
服务于正式推荐历史和运行监控，不得反向参与当天评分、离线验证或阻塞启动。V1/V2 历史比较必须覆盖
同日、同股、同一封存输入下全部共同可评分候选，而不是只观察最终 Top6；合法空仓日同样进入历史组合
结算。没有足够样本外证据时必须写“未证明”，不得用工程完成、推荐数量或人工授权代替收益证明。

最终 V2 评分口径只产生 `ScoredDecision`，Long 只产生无评分 `LongProjection`；新 release
不得构造或读取旧 `RecommendationSnapshot`，也不回放旧策略、旧引擎或旧 schema。当前
V2-only 工程与发布门禁验收已闭合；当前版本仍在 `Unreleased`，尚未声明正式
`0.2.0` release。旧链已从活动树物理删除，不定义候选、公式、
风险、融合、动作或排名。历史问题与实施过程只进入 `CHANGELOG.md` 和报告。

## 1. 策略目标与共同纪律

- `today`：盘中短线，面向 T+1；11:20 冻结。
- `tomorrow`：上午生成滚动本地草稿并复用跨策略模型 facts，13:00 后增加尾盘量价和
  增量模型复核，面向 T+1；14:50 冻结。
- `d25`：上午生成滚动本地草稿并复用跨策略模型 facts，13:00 后增加增量模型复核，
  面向 T+2 至 T+5；14:50 冻结。
- `long`：固定长期潜力龙头研究池，只展示当前行情快照；warmup、上午和下午都可随统一
  行情生成当前观察快照，不运行荐股策略、不冻结、不产生交易动作、不写推荐历史。

允许 0 只推荐。所有计算只使用观察时点已经生效的数据；实时价格、涨跌停和冻结锚点
使用未复权价格，历史收益、均线、波动和回撤使用点时可得的前复权序列。行业、证券
状态、财务和规则按实际生效时间进入特征。每次输入绑定交易日、阶段、数据、规则、
行业、配置、因子 schema、策略和引擎版本。

缺失原始值保持 `null` 并记录 `missing_fields` 与 `missing_reasons`。允许用于确定性评分
的中性占位为 50，但不得把占位序列化成真实观测，也不得通过缺失字段获得额外优势。
非有限数值、未来数据、无时区数据、截止后结果和无法验证的证券状态不得用于可执行
推荐。

### 1.1 tomorrow v2 收益与选择目标

tomorrow 是目标架构唯一最高优先级的生产选择任务，在交易时段滚动发布本地预览并于
14:50 冻结。每个决策允许 0 到 6 只正式推荐和 0 到 6 只观察项；候选不足或全部未通过数据、风险、动作和集中度
门槛时必须返回真实空结果，禁止为凑数降阈值。

首要收益标签固定为 14:50 锚点至下一交易日收盘的相对全市场等权净超额收益，并同时
报告下一交易日最低价对应的 MAE/ATR20、换手和行业集中度。成本敏感性统一使用
20bp、50bp、100bp 三档往返成本，不得只展示最有利口径。

DeepSeek 继续参与融合分，但只能复核候选池内股票、返回经 schema 与证据校验的 facts，
不能放宽硬过滤、引入池外股票或用自由文本直接扣分。任何新挑战者在历史 point-in-time 留出门禁通过并
经独立生产批次授权前，正式融合继续使用当前固定 68/32 公式。普通阶段全策略合计目标 36、硬上限 66，
其中 tomorrow 独占目标 21、硬上限 38；失败、超时和重试同样计数，耗尽后保留 local
决策，不阻塞发布或冻结。独立 emergency 桶和全局 168 次灾难保护线以第 11 节为准。

## 2. 板块身份与交易规则

板块固定为 `main`、`chinext`、`star` 和 `unsupported`。识别顺序为带生效时间的证券
主数据、交易所清单、行情源市场字段、六位代码前缀降级。前缀降级记录
`board_source=code_prefix_fallback` 和 `board_reliability=degraded`；来源冲突记录
`board_classification_conflict`，只能观察。

每个观察点保存：板块、来源、可靠度、交易所、上市日期、上市交易日龄、是否有价格
限制、交易所限制比例、策略热度上限、规则版本和生效日期。

首次上市第 0-5 个交易日、重新上市首日、退市整理首日直接排除，第 6 个交易日起才用
普通规则。上市日期或交易日龄不可验证时只能观察。普通热度边界：主板 8.00% 通过、
8.01% 剔除；创业板和科创板 16.00% 通过、16.01% 剔除。无价格限制状态不计算普通
`limit_proximity`。

## 3. 统一行情与点时合并

策略只消费不可变统一行情，不直接读取供应商对象。相同有效输入无论来源完成顺序都
产生相同字段归属、来源版本、冲突集合、缺失集合、合并 epoch 和规范 JSON 哈希。
合并 epoch 绑定排序后的已接受观测身份、点时、版本、载荷哈希、缺失原因和定向范围；
最终规范 JSON 哈希继续覆盖完整统一快照，两者不得用不稳定对象地址或输入完成顺序生成。

同来源先按来源时间、接收时间选择较新字段；跨来源同时点按既定优先级。新鲜腾讯
候选价只能在与东方财富或新浪至少一个全市场观测偏差不超过 0.50% 时完成冲突复核，
不得自证。慢数据不得覆盖更新的实时价格。全源失败时沿用最近有效统一快照并降级，
不能生成空快照清除推荐。
未准入影子来源不得写入统一行情字段，也不能参与候选、过滤、评分、DeepSeek 证据、
冻结或收益结算；通达信/mootdx 在权威准入前只可作为独立影子观测，不构成候选 fallback。

## 4. 硬过滤

硬过滤分成一级永久资格过滤和二级动态硬过滤。一级是所有逐股 I/O 的前置资格门，二级才在
当前点时特征形成后执行。两级都使用确定性结构化规则，不能由 DeepSeek 放宽、删除、创建池外股票，
也不能让模型自由文本直接改变资格。

### 4.1 一级永久资格过滤

`IssuerEligibilityRegistry` 以追加事实保存永久名单。任一不晚于评估时刻的一级事实命中后，状态固定为
`permanently_excluded`；尚无永久事实但覆盖尚未闭合时分别保留 `eligible_unverified` 或
`qualification_pending`，不能把未知伪装成已核验无风险。一级永久事实只包括：

- 正式年度财报已经披露归母净利润或扣非/核心净利润小于 0，原因码为
  `historical_audited_loss`；季度亏损、业绩预告和媒体转述不属于该口径；
- 任一历史点时行情或证券状态已经确认 ST、`*ST`，原因码为 `historical_st`；名称含“退”或正式
  退市风险警示另记历史退市警示；
- 监管、交易所、发行人或司法结构化证据正式确认的财务造假、重大违法、资金占用、违规担保或
  强制退市，以及配置中的人工永久黑名单。

事实必须绑定证券代码、原因、事实生效时间、稳定证据 ID、来源和 SHA-256；相同证据同内容幂等，
不同内容冲突失败关闭。普通新闻、DeepSeek 自由文本、问询函、一般诉讼、亏损预告和仍在进行但未形成
正式结论的调查不得创建一级永久事实，也不得解除已有事实。一级名单只增不减；更正或申诉不能静默
覆盖旧记录，只有未来另立、经人工授权的权威规则版本才能改变生产口径。

一级资格必须在历史预热、候选定向行情、逐股公司研究、参考数据、Long 定向行情和分钟行情调度前
过滤代码；已排除代码不得进入这些请求，也不得进入评分或 DeepSeek 队列。全市场批量接口可能因供应商
只支持整批下载而物理返回已排除行，但发布人口、缓存下游和全部逐股请求必须立即剔除，不能为排除代码
追加下载历史数据。既有运行库中已下载的历史数据不在本批物理删除，防止破坏冻结记录与审计证据。
冻结后的正式 TopK 只允许继续更新报价 overlay，既有 outcome 也可按原冻结身份结算；两者不能借一级
名单追溯改写正式记录。

历史研究和回放必须按事实生效时间重建当时资格：只有 `effective_at <= decision_at` 的事实可以排除
该历史样本，不得用当前一级名单反向删除事实生效前的股票或回填未来结论。H1 必须封存这一事实时间线，
而不是只保存当前名单快照。

### 4.2 二级动态硬过滤

一级通过后，候选依次执行带严重级别的动态确定性过滤。当前 `FilterSeverity.REQUIRED` 二级必需阻断包括：

- 非六位受支持 A 股代码或 `unsupported` 板块，ST/`*ST`/名称含“退”、停牌；
- 价格或成交额非有限、非正，行情时间无时区、来自未来或超过本阶段动作年龄；
- 跨源偏差字段本身非法，开高低收结构非法或当日涨跌幅缺失/非有限；
- 上市第 0-5 个交易日、重新上市首日、退市整理首日；
- 20 日成交额中位数缺失、非有限或低于 5000 万元；
- 一字涨跌停或行情已标记重大监管风险；
- 超过板块热度上限；
- 经点时 schema 和官方证据验证的 `major_shareholder_reduction`、
  `financial_fraud_history`、`official_investigation_history`、
  `major_illegal_history`、`fund_occupation_history`、`illegal_guarantee_history` 或
  `forced_delisting_risk` 命中；
- `unlock_risk > 0`、`pledge_risk > 0` 或 `financial_deterioration > 0.5`。

当前可选告警/观察限制包括：未复核的跨源价格偏差超过 0.50%、
`board_classification_conflict`、`board_identity_degraded`、`missing_listing_date`、
`missing_listing_age_sessions`、`structured_risk_unavailable` 和
`corporate_risk_history_unavailable`。这些事实写入 `optional_flags`；统一行情同时写入
`execution_restrictions` 时，最终动作即使达到阈值也会改为 `observe`。候选必需字段缺失
比例超过 30% 属于板内预选剔除，不冒充硬过滤；
板块数据可靠度低于 0.85 属于动作门和 DeepSeek 资格限制，同样保留本地候选但只能观察。

二级硬过滤仍是结构化规则。可选告警进入
`optional_flags`，不冒充阻断原因；必需阻断保存在 `filter_reasons`。原因码必须细分到
具体板块和事实，例如 `chinext_board_too_hot`、`star_board_too_hot`，不能用模糊成长
板标签替代。

严重公司风险只接受发行人、交易所、监管或司法结构化披露及其稳定证据 ID；新闻标题、
DeepSeek 自由文本和普通风险提示、问询函、一般诉讼、亏损预告不能创建或解除硬事实。
规则固定为：

- 大股东指控股股东、实际控制人和持股不低于 5% 的股东；减持计划从公告起阻断，至官方
  完成或终止后 90 天解除，无终态则持续阻断；
- 官方决定确认的财务造假、虚假记载、重大遗漏、重大违法、资金占用和违规担保永久阻断；
- 正式立案调查和强制退市程序在存续期及官方结案、撤回或终止后三个自然年阻断，满三个
  自然年当日解除。

风险事实随研究缓存持久化合并，旧命中不能因本轮来源失败消失。来源失败或覆盖状态不可
确认时不能猜成 0：已确认事实继续阻断，其余候选保留本地快照但动作降为观察，并记录
`corporate_risk_history_unavailable`。减持、解禁、质押必须保持独立字段。
财务、公告/公司风险历史、质押和解禁是四个独立覆盖分项；程序运行时按分项 TTL 复用缓存，
并非每次评分都重新请求，也不是进程一生只请求一次。批次超时只延后未完成股票，已经完成
股票和分项立即形成新研究版本。上述采集与覆盖状态独立于 DeepSeek 模型复核。一般负面新闻、
普通问询、一般诉讼和未经正式财报确认的亏损预告仍只作研究提示，不能新增硬过滤；正式财务
报告触发 `financial_deterioration > 0.5` 或官方结构化风险事实命中时才按本节既有阈值阻断。
CNInfo 公告增量链只保存带稳定公告 ID 的结构化披露、公告组件状态和来源游标；重复页按公告
ID 去重，空增量只更新游标和审计，不能把既有 `known_risk` 覆盖为 `known_clear`。交易所公告
交叉校验未形成正式来源前，CNInfo 证据的 `exchange_cross_check_status` 固定为 `pending`，
可进入本地风险事实注册表和观察降级判断，但不得宣称已完成交易所级复核。
东方财富发行人公告必须按实际 100 条单页上限有界遍历并以稳定公告 ID 去重；缓存已有完整历史时
允许用新首页与旧基线做增量合并。只有不晚于评估时刻的有效公告数量覆盖供应商 `total_hits` 时，
`announcement` 分项才能成为 `known_clear` 或 `known_risk`；分页不完整继续
`corporate_risk_history_unavailable`，不能通过减少回看窗口或只读首页解除观察门。

## 5. 板内总体与成交因子

横截面总体固定为：

```text
trade_date + phase + board + data_version
```

流动性、换手、波动、回撤、趋势和相对强度均在板内按
2.5%/97.5% 截尾、归一化和稳定排序。有效板内横截面至少 100 只；不足时最多回退最近
5 个有效交易日的同板同阶段总体，不能借用其他板块。

板内总体与本轮候选是两个不同集合：全市场特征只用于按
`trade_date + phase + board + population data_version/merge_epoch` 构建和缓存总体、
分位与归一化基准；候选定向报价完成后，只把每板最多 120 只的新鲜候选投影到该基准并
计算候选分和本地分。不得再次对约 5500 只全市场股票逐只执行九组候选选择和本地评分，
也不得先从全市场选出另一批股票再与本轮候选代码求交集。候选报价版本变化只失效相应
候选批次和逐股本地分，不得无条件失效未变化的板内总体。候选预选与正式评分必须沿用
同一份全市场特征自带的 `merge_epoch`；缓存只保留总体参数和参考分布，命中后不得为
每个策略重复序列化全市场，正式评分只投影有界候选并直接执行纯本地评分函数。
全市场总体与候选定向批次必须分别使用自己的点时水位和年龄上限：总体在其完整发现批次的
`observed_at/source_time/received_time` 最大值上执行预选新鲜度审计，候选在最终
`evaluated_at` 上执行评分新鲜度审计。候选历史、研究或分钟增强较慢，不能把此前已完整接纳的同一
`merge_epoch` 总体倒算为 `stale_quote` 并清空横截面；候选原始 `source_time` 过期时仍必须拒绝，
不得借总体水位恢复候选执行资格。原生输入边界必须先把总体与候选的全部业务时间规范为
`Asia/Shanghai`，再计算最大水位，不能让 `max()` 保留胜出 UTC 对象的时区身份。

行业只用于展示、审计、DeepSeek 行业政策零权重标签和最终集中度标识，不进入候选分、
本地分、DeepSeek 总分、动作门或活动下行保护。特征服务仍计算并保存

## 7. 本地评分

定义带通函数 `B(x;l,o1,o2,u)`，其中 `l < o1 <= o2 < u`：`x <= l` 或 `x >= u`
得 0，`o1 <= x <= o2` 得 100，两侧区间线性变化。参数非法时配置拒绝启动，缺失或
非有限输入按缺失规则处理。`P(x)` 是 0-100 横截面平均秩，反向因子必须登记并计算
`100-P(x)`。

统一计算边界：

```text
base_score = sum(component_score * component_weight)
local_score = clamp(base_score - local_risk_penalty, 0, 100)
```

### 7.1 确定性入场质量

tomorrow 和 d25 的 `entry_quality` 取缩量回踩与放量突破两类确定性形态的
较高值。热度本身不阻止入选；只有形态、下行保护和既有硬过滤共同决定是否可执行。

- 缩量回踩：`MA5 >= MA10 >= MA20`、MA20 斜率向上，价格距离 MA5 不超过 1% 或距离
  MA10 不超过 2%，点时 `volume_to_5d_average` 不高于 0.70，且价格不低于 MA20。
- 放量突破：价格不低于前 20 个完整交易日最高价，点时 `volume_to_5d_average` 不低于 2.0，
  收盘位置不低于 70，突破偏离不超过 5%。
- `volume_to_5d_average` 优先使用供应商点时 `volume_ratio`；供应商未提供时，使用同日
  点时成交额除以最近 5 个已完成交易日平均成交额派生，不使用同日历史 bar。
- 完整形态为 100，趋势前提成立但入场确认不完整为 50，趋势破坏为 0；必要输入缺失
  保持 `null`，不能以中性值冒充确认。

行业组件移除后，其权重按各策略剩余组件原比例归一化；`entry_quality` 保持上述确定性
形态定义。过热事实继续审计和软扣分，不再作为 d25 独立正向组件。

### 7.2 tomorrow v2 确定性本地选择

tomorrow v2 旁路选择只消费同一数据平面快照：昨日及更早历史、证券主数据和结构化风险来自
`DailyFeaturePack`；全市场当前报价来自其父版本匹配的 `MarketEpoch`；当日尾盘、入场、
执行质量和日内结构风险只能由 `CandidateQuoteEpoch.CandidateFeatureRow` 覆盖。实时特征
白名单不得包含财务、公司风险或证券身份字段。候选价格必须携带本轮跨源偏差并满足
`cross_source_verified=true`、偏差有限且 `<= 0.50%`；不得沿用旧全市场价格的复核状态。
候选单股来源时间早于父市场同股报价时，候选价格及同批实时特征都不得覆盖更新值。

该快照只通过应用层 `DataPlaneReadPort` 读取。`DailyFeaturePack` 发布前必须证明潜在可执行
代码的证券主数据覆盖为 100%；候选历史覆盖率作为健康和容量指标公开，不再拥有整批发布否决权。
每只候选按活动策略/profile 的类型化数据需求独立判定评分资格，缺失只排除该股票并记录稳定原因；
仍有合法评分人口时必须继续评分，完全无合法评分人口才报告未就绪，禁止把数据不足解释成策略真实空集。

活动生产适配器必须在本地决策发布前复核逐股资格。候选定向特征须覆盖全部请求代码；证券身份完整表示受支持板块且
不存在 `board_identity_degraded`、`missing_listing_date` 或 `missing_listing_age_sessions`；
历史资格不是统一的 20 日布尔值：Today 与当前启发式 D25 至少登记 20 日流动性/风险摘要；Tomorrow
V1/V2 因使用 20/40/60 日 skip-5 动量，必须具备至少 61 个有效 qfq 交易日及所选模型全部字段。
证券身份仍必须 100%；历史资格逐股执行，覆盖率只作诊断。部分股票不合格时发布其余合法评分，
活动模型字段资格必须在板内候选限额前执行，禁止不合格股票占用名额并挤掉可评分股票；全部候选均
不合格时返回 `transient_invalid_empty/not_ready`，不得发布 `business_empty`。

逐股过滤状态固定为：

- `reject`：任一必需硬过滤失败，不进入板内候选分；
- `observe_only`：硬过滤通过但存在可选告警，或板块数据可靠度低于 0.85；保留本地分和
  审计，不进入 DeepSeek 或正式 TopK；
- `pass`：必需过滤通过、无可选告警且板块可靠度达标，可继续参加正式本地选择。

每板先按可靠度是否达标、候选分降序、代码升序稳定截取最多 120 只，再计算本地六组件和
本地风险。本地风险只从 `base_score` 扣一次，输出 `local_score`；DeepSeek 后续融合不得
再次扣 `local_risk_penalty`。全局按本地分降序、候选分降序、代码升序稳定排序，只从
`pass` 且达到 `tomorrow 阈值 - observation_margin` 的候选中选最多 6 只，每行业最多
2 只。允许真实空结果；`observe_only` 候选在独立观察集合中展示和审计，不占正式 TopK。

候选核心缺失超过 30%、候选分低于 50、每板 120 上限、本地风险 veto、本地门槛、行业上限
和 TopK 上限分别记录稳定原因码，不得合并成“本轮没有可评分候选”。相同 epoch、配置、
fallback 和评估时间无论输入顺序如何都必须产生相同逐股状态、分数和选择顺序。

### 7.3 long 固定研究池

long 不是荐股策略，不计算价值、成长、质量、风险保护或任何旧长期评分，不调用
DeepSeek，不执行 TopK/行业集中度选择，也不把研究字段缺失标记为策略降级。long 只从
版本控制的 `long_watchlist.json` 读取固定股票池和分组，按配置顺序生成 `observe` 观察项，
不生成评分字段并标记 `score_status=not_applicable`。long 不借用评分字段伪造荐股决策形状，
也不代表投资判断。运行时不得把 long 送入任何策略评分或 finalize 链。

long 固定池的准入语义是“长期潜力赛道中的头部或弹性龙头观察标的”：卡脖子行业优先
关键环节国产替代龙头，高成长赛道优先产业趋势清晰且全市场关注度靠前的龙头，低价潜力
股优先芯片、智能制造、算力卫星、材料资源和种业方向中价格弹性更强的细分观察标的。该准入语义只约束固定名单维护，
不构成收益承诺，也不允许运行时按旧 long 评分、DeepSeek 或实时价格自动换股。

长期分组分三类：

- `chokepoint`：卡脖子行业分组，来源为 `main` 历史中的
  `CHOKEPOINT_INDUSTRY_LEADERS` 并按关键核心技术、关键零部件、关键基础材料、关键软件和
  产业链供应链安全口径校正；脑机接口按公开年报和公告证据维护独立分组，AI 基础设施拆为
  `AI算力`、`液冷` 和 `数据中心电源` 三个独立分组；固态电池按长期细分行业量化复核报告
  的正式通过结果维护独立分组，不把未达标候选继续留在高成长混合分组。2026-07 战略方向
  合并进一步把混合的科学仪器/医疗装备拆为 `高端科学仪器` 与
  `生命科学/高端医疗装备`，把精密零部件校正为 `高端传感器/精密测量`，并新增
  `航空发动机/燃气轮机`、`新型电力系统/储能` 和 `可控核聚变关键材料/装备`；
  迁移已有股票时保持全局唯一，新补充股票必须有交易所公告、定期报告或公司正式披露支持
  其关键环节关系，不能用市场概念标签代替。卡脖子每个行业只保留
  一个左侧分组按钮；组内股票按 `document_scan` 与 `current_leaders` 两个来源 section 排序：
  先保存 `docs/reports/a-share-long-industry-research-2026-07-24.md` 的正式通过名单，再保留
  当前固定龙头补充；每个行业合计最多 5 只固定观察股。
- `future_growth`：高成长赛道分组，按 2026-07-24 可见官方产业政策口径和全市场长期涨幅
  复核形成固定观察池，覆盖低空经济、商业航天、光模块、具身智能、智能电动汽车、
  创新药/高端医疗、生物制造和量子通信/6G 等方向；每个赛道最多 5 只。

## 8. 执行质量、可靠度与容量

板内容量层级固定为：低于 P50 为 `liquidity_observe`，P50 至 P80 为
`normal_capacity`，P80 及以上为 `high_capacity`。板内样本不足时保持保守或缺失，
不能跨板借用阈值。

可靠度由来源新鲜度、字段完整度、板块身份、横截面规模和冲突状态构成，
范围 0-1。可靠度低于 0.85、行情超动作年龄或价格冲突未解决时，不产生新的可执行动作，

执行质量只描述在公开行情下的相对容量和价格限制风险，不预测真实成交，不生成仓位、
资金规模或下单建议。

同一事实不因多来源或模型重复描述而重复扣分；本地风险总扣分有界，活动测试要求覆盖
七类事实、去重和 25 分截断。

活动短线风险及固定扣分为：

| 风险代码 | 含义 | 扣分 |
| --- | --- | ---: |
| `near_limit_crowding` | 接近板块价格限制的追高拥挤 | 5 |
| `price_volume_divergence` | 价格与成交量/成交额确认方向背离 | 4 |
| `high_volatility` | 20 日波动率进入登记的极端区间 | 3 |

### 9.1 活动下行保护

融合公式保持不变，下行保护在融合后、动作和 TopK 前独立执行。保护结果为 `pass` 或
`observe`，高分和高热度不能覆盖 `observe`。下列任一条件将可执行候选降为观察：

- 从当日最高价回落至少 1 个 ATR20，且收盘位置不高于 35；
- `trend_breakdown` 命中；
- 板内 `low_volatility_score <= 20` 且 `low_drawdown_score <= 20`；
- `market_regime=risk_off`、市场上涨宽度不高于 30，且 tomorrow/d25 尾盘收益为负或
  收盘位置不高于 50；today 使用 5 分钟收益为负或收盘位置不高于 50；
- ATR20、20 日波动、20 日最大回撤、低波动分或低回撤分缺失、非有限或过期。

`short_term_overheat`、高波动或临近涨停单独出现时仍只按既有风险表软扣分，不构成
下行保护降级。结构化监管、财务和交易规则 veto 保持 `unavailable`，不降格为观察。

七项理论合计和截断上限均为 25；无事实时扣 0。普通连续弱势只由基础组件反映，不能
重复触发离散扣分。缺失、非有限或样本不足不触发扣分，只记录缺失。long 不使用这组
短线结构扣分。风险事实保存实际值、阈值、方向、严重度、证据、生效时间、互斥/叠加
组和本地规则版本。

模型自由文本、评级、置信度、情绪形容词或未经证据验证的结论不能直接决定扣分、veto、
动作或排名。

Today、Tomorrow、D25 的统一 V2 决策必须显式调用本节保护器。调用点固定在 local/hybrid 融合
完成之后、动作判定和正式池/观察池集中度选择之前；保护只把原本达到执行门槛的候选降为
`observe`，原因使用 `downside_guard:<受控原因>`，不得修改 `local_score`、`final_score` 或融合
组成，也不得把低于观察门槛、硬拒绝或 veto 候选提升为观察。观察池原本就不可执行时保持既有
动作语义，避免把保护器误用成补数或新的排名加分。

## 10. DeepSeek 结构化复核

DeepSeek 是可选复核器，不是候选生成器。默认使用受控双模型：V4-Flash 非思考主审，
V4-Pro 思考挑战者仅处理预注册的不确定、高风险或边界案例。供应商不可用、密钥缺失、
超时、预算耗尽或 schema 失败时回退本地推荐，并明确 `local_degraded` 或相应终态。
若硬过滤、板块样本或可靠度门槛使本轮没有可复核候选，必须标记
`deepseek_skipped_no_eligible_candidates`；未发生物理请求时不得标记
`deepseek_incomplete`。后者只表示已有可复核候选但请求、预算、响应或校验未完整完成；
long 永久不进入复核，因此不得附加任一 DeepSeek 降级原因。

活动结构化事实接缝固定为 `deepseek_v4_review_facts_v1`。该接缝只允许模型返回可校验
事实，不允许自由文本、评级或置信度直接决定分数、风险、动作或排名。事实
集合固定包含：催化方向、重要度、确认状态、周期和引用；价格反映桶；基本面状态；行业
政策状态；监管、减持、解禁、质押、诉讼和业绩风险；事实冲突；证据覆盖；以及
`abstain`。每条事实必须引用本地 manifest 中的证据 ID、来源等级、发布时间和摘要哈希；
无法用 schema 与证据核对的字段必须拒绝或转为 abstain。

每只候选最多使用 12 条点时证据，首轮槽位仍按结构化行情 1、尾盘分钟 1、财务与研究
3、监管/质押/解禁等风险 4、新闻与公告 7 的顺序依次填充，达到 12 条即停止。空槽按
监管风险、财务研究、分钟量价、新闻公告的顺序补给；补位后监管最多 6、财务最多 5、
新闻公告最多 8，行情和分钟仍各最多 1，总数仍不得超过 12。跨来源同主体、事件 key
和证据分类的记录只保留质量更高且更早接收的一条；存在有效相反材料时至少保留一条
反证。证据 manifest 必须携带 `source_tier` 和 `event_key`，正向加分只接受官方来源或
两个独立可信来源支持。

V4 事实只由本地纯函数映射，原始维度从 50 分开始并限制在 30-70；模型不能直接返回
维度分、生产扣分或 veto：

| 结构化事实 | 本地原始变化 | 投影维度 |
| --- | --- | --- |

## 12. 融合、动作与稳定排名

固定公式：

```text

    local_score * 0.68
    + deepseek_score * 0.32
    - deepseek_risk_penalty,
    0,
    100,
)
```

`local_score` 已扣本地风险，融合时禁止再次扣 `local_risk_penalty`。所有输入使用十进制
确定性计算，最终以 `ROUND_HALF_UP` 保留两位小数。固定验收向量结果必须为 `83.40`。
未应用有效 hybrid 时（无复核、复核拒绝/弃权/迟到、覆盖率或已知维度不足，或当前模式

schema、证据与本地规则映射的独立 veto 仍可保持更保守动作。
本地事实已经形成的 veto 与模型事实映射形成的 veto 使用逻辑 OR 合并；有无模型复核都不得覆盖、

生产排序固定为：`final_score` 降序、`local_score` 降序、股票代码升序。模型评级、
置信度、挑战状态和自由文本不得改变同分顺序。

#### 15.1.19 V1/V2 差异与既有收益证据

两种生产评分都在相同硬过滤后的 Tomorrow 候选上只替换本地 `base_score`；其后的本地风险、固定 68/32
融合、78/73 动作门槛、Top6、行业/板块集中度、DeepSeek 预算、14:50 冻结及 T+1 结算完全相同。
差异固定如下：

| 维度 | V1 | V2 |
|---|---|---|
| 模型 | 三因子 ridge 线性代理 | 六因子 ridge/LightGBM 各 50% 集成 |
| Alpha | 20/40/60 日 skip-5 残差动量 | 1/3/5 日收益与同组三个残差动量 |
| 成本与分数 | 扣 20bp Amihud 成本后按正净效用横截面映射 0–100 | 同左 |
| 模型分歧 | 单模型，固定为 0 | ridge 与 LightGBM 预测差绝对值 |
| 历史证据 | 同一 H0 留出集 139 日、687,321 条配对；20bp 平均净增量和 bootstrap 下界均为负 | 原 P2 留出 139 日、678,370 条配对；平均净增量为正但被风险/排序门禁拒绝 |
| 主要特点 | 结构简单、输入较少、可解释，但当前留出收益证据为负 | 平均收益信号证据较强，但换手和严重亏损风险明显更高 |

关于“哪个荐股更能挣钱”，当前唯一诚实结论是：尚不能认定 V1 或 V2 是可重复的未来收益胜者。V2 相对
H0 历史代理在 20/50/100bp 下的平均成本后净增量均为正，且 20bp 区块 bootstrap 下界为正，因此
V2 的平均成本后净增量证据强于 V1；但它同时出现严重亏损率 15.9472% 对 8.2734%、换手增加
56.2350 个百分点及 Q5-Q1 为负，已被预先固定的门禁拒绝；V1 同口径留出的 20bp 平均日组合净增量和
bootstrap 下界又均为负。故不能据此断言 V2 未来更能挣钱，也不能因为 V1 更简单就宣称 V1 风险调整后
更优。默认 V1 仅表示用户指定的日常选择，不表示收益保证或研究晋级。

**V1 任务状态**：

1. 已用与 V2 完全相同的 H0 验证日期、候选代理、成本和门禁完成只读独立留出评估；训练段没有重拟合
   或调参，报告身份为 `tomorrow_v1_v2_h0_holdout_report_v2`、hash 为
   `47e2b9bfd4d404521f8251e2e51c491aa96c1bc0d8423dea95e63320daa6e3bf`，固定 139 个验证交易日和

   门禁；因此 V1 没有取得可切换生产的收益证据。
2. 当前人工 V1 是独立人工代理；原 P1 研究身份只作历史审计，不是活动路线、待办或当前 V1 的
   前置条件，也不得借其名称替 V1 背书。
3. 单一线性头仍没有模型分歧，也没有逐股严重亏损概率；若要提供这两项，必须另立 V1.x 模型、校准数据、
   schema 和发布批次，不能把固定 0 或总体亏损率伪造成逐股指标。

**V2 任务状态**：

1. 既有 P2 历史路线已经 `historical_rejected`，P2-2/P2-3 不是待办而是禁止继续的终止分支；不能放宽

   60 日训练、20 日 Platt 校准、40 日独立检验、1 日 embargo、Brier/ECE 可靠性和单次终止规则。

当前证据结论以上述 H0 留出和 P2 历史报告为止，不设跨年配对采集任务，不把任何运行计数列为待办、

每个合格股票日的主标签固定为
`(close[D+1] / close[D] - 1) - eligible_universe_equal_weight_return[D+1] - round_trip_cost`。

`D+1`，特征、过滤和候选代码不得访问未来列。

基础 Alpha 固定为前复权 1/3/5 日收益和 20/40/60 日 skip-5 残差动量；动量依次扣除同日市场、稳定板块

分层、风险诊断和平局。股票代码、当前行业、当前风险状态和 DeepSeek facts 不得成为基础模型特征。
当前历史日线核心不能证明点时行业身份，首版禁止行业修正。

预注册模型家族固定为五个共同检验候选：Ridge、固定浅层 LightGBM、两者各 50% 集成、集成加板块/
流动性/波动的强收缩样本外残差修正，以及前一候选再加极强收缩个股残差的消融。分层边界、最小样本、
收缩常量和截断在读取确认段前封存；个股残差至少需要 250 个成熟样本和 120 个不同交易日，收缩常量不得
小于 1,000 个等效观测，绝对修正不得超过预测日横截面预测标准差的 10%。股票代码只作残差归属键；
样本不足时个股修正为 0。个股层未能在确认和终端留出相对无个股层独立增益或增加严重亏损、换手、集中度
时，最终工件必须删除个股表。

C3 唯一冻结管线确定后，再用同一开发段内 V1、V2、C3 的样本外原始预测训练 V3 联合器。联合候选固定为
C3 单模型、V1+C3、V1+V2+C3 三个，共同纳入多重检验；每个输入先使用当前训练折的同日横截面统计标准化，

同一联合结构内部可用开发折预测误差选择正则强度，但三个最终结构之间必须按开发段完整组合回放的
20bp/50bp 配对净增量、区块下界和风险门禁选择，禁止用 MSE、训练误差或涨跌命中率代替收益目标。联合器
只读原始预测和成熟标签，不读取子模型 `base_score`、股票代码、DeepSeek、动作、Top6 或未来状态。

扣除为第 15.1.32 节保留的最新至少 200 日后，剩余交易日固定为最旧 60% 开发、随后 20% 一次性确认、

embargo；开发段执行 5 折 expanding walk-forward。所有预处理、模型和残差修正只从当前折训练段拟合，
