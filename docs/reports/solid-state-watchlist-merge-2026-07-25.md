# 固态电池正式结果合并说明

日期：2026-07-25

## 用户问题

`docs/reports/a-share-long-industry-research-2026-07-24.md` 已给出经过财务、历史行情和主营
复核的正式股票，但活动长期名单仍保留原人工固定池，没有把固态电池正式结果合并进卡脖子行业。

## 原因与修改

- 原配置把固态电池放在高成长 `新型储能/固态电池` 混合分组，未把研究报告正式结果作为活动配置。
- 新增卡脖子独立分组 `固态电池`，迁入报告正式通过的国轩高科 `002074`、当升科技
  `300073`、亿纬锂能 `300014` 和恩捷股份 `002812`。
- 删除高成长混合分组，避免相同股票跨分类重复。
- 容百科技 `688005` 未出现在报告该行业的正式通过表中，因此从活动长期名单移除，不为凑满
  5 只而保留。

## 行为变化

长期页进入 `卡脖子行业` 后可选择 `固态电池`，右侧展示上述 4 只固定观察股票；高成长页不再
显示 `新型储能/固态电池`。本次只改变固定研究分类，不代表买入建议或收益保证。

## 数据边界与剩余风险

- 合并依据是数据截止到 2026-07-24 的首轮量化复核报告，不是全市场持续自动选股。
- 报告主营摘要不能替代公告级固态电池技术路线、量产进度和收入贡献核验。
- 固态电池产业和公司项目进度会变化，后续仍需按新财报和公告重新复核。
