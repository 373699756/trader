# 卡脖子长期名单文档分区说明

日期：2026-07-25

## 用户问题

最近两次提交已经包含长期行业扫描报告和部分卡脖子分组调整，但活动长期名单仍没有把卡脖子
行业按扫描报告正式结果整体分区展示；页面左侧也无法区分“文档正式名单”和“当前这些龙头股”。

## 原因与修改

- `docs/reports/a-share-long-industry-research-2026-07-24.md` 已给出卡脖子正式通过名单，但
  活动配置此前只合并了脑机接口、AI 基础设施拆分和固态电池等局部变化。
- `long_watchlist.json` 在每个分组中新增 `sections`：`document_scan` 保存扫描报告正式名单，
  `current_leaders` 保存当前固定龙头补充。
- 卡脖子仍保持一个行业一个左侧按钮；固态电池按报告正式结果纳入文档 section，报告正式通过
  为 0 只的行业只在确有当前龙头补充时保留按钮。
- 页面右侧股票列表先显示文档正式股票，再用横向分隔线接续当前龙头补充，避免因为来源分区而
  增加过多行业 tab。

## 行为变化

长期页进入 `卡脖子行业` 后，左侧仍按行业选择；右侧同一行业股票列表中，分隔线以上为扫描
报告正式名单，分隔线以下为当前龙头补充。右侧仍只展示所选分组内固定观察股票的实时行情字段，
不展示静态财务或公告文案，不代表买入建议。

## 数据边界与剩余风险

- 扫描名单的数据截止日为 2026-07-24，不是持续自动选股。
- 报告中的主营摘要只能证明业务相关性，不能替代公告级国产替代、客户验证和收入占比核验。
- 当前龙头补充保留原固定池语义；后续若要删除未进入扫描正式名单的补充项，应作为新的独立
  固定名单维护任务执行。
