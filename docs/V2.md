# V2 唯一产品目标

> 状态：V2-only 最终 release 已完成验收，不保留旧版运行时兼容。
>
> 本文只给出目标概览。产品、架构、时间线、API、运维和验收以
> `docs/software-business-design.md` 为唯一权威；候选、过滤、评分、风险、DeepSeek、融合和
> 排名以 `docs/recommendation-strategy.md` 为唯一权威；实际施工顺序以
> `docs/implementation-plan.md` 为准。

## 1. 最终形态

最终 release 只允许存在一条活动链：

```text
公开数据源
  -> V2 采集、标准化与字段质量
  -> V2 点时数据平面
  -> V2 原生策略输入
  -> today / tomorrow / d25 决策与 long 行情投影
  -> V2 当前索引、冻结仓储与报价 overlay
  -> V2 查询、API、SSE 与根页面
```

V2 必须独立拥有配置、数据、调度、决策、冻结、查询、事件流、Web 和生命周期。最终
`bootstrap.py` 不再构造旧 Pipeline、旧快照发布器、影子比较器或旧 Web 服务。

## 2. 无兼容原则

- 新 release 不读取旧运行目录、旧数据库、旧快照、旧 schema 或旧冻结格式。
- 不提供旧 URL 别名、重定向、双读、双写、旧 envelope 或浏览器兼容脚本。
- 不保留为旧策略、旧引擎或旧 Web 服务的回放分支。
- 不保留 V1/V2 同输入比较、cutover gate、shadow evidence 或运行时生产指针。
- 旧数据可以在仓库外只读备份，但不进入新 release 的导入、启动、查询或恢复路径。
- 回退只允许启动完整旧 release 和它自己的旧运行目录；新旧代码、配置和数据库不得混用。

最终 release 只保留 V2 组合根和 V2 资源；后续开发不得重新引入旧实现或反向依赖。

## 3. 唯一运行契约

- V2 唯一运行目录为 `.runtime/v2`，只接受当前 V2 schema。
- `config/v2` 是唯一配置目录，`pyproject.toml` 是依赖、构建和入口的唯一权威。
- `trader-server` 和 `trader-cli` 是唯一进程入口。
- `bootstrap.py` 是唯一组合根；`create_app()` 保持无线程、无网络、无数据库和无文件写入副作用。
- 所有业务时间使用 `Asia/Shanghai`，时钟显式注入且带时区。
- HTTP 只执行应用层只读查询，不抓行情、不评分、不调用 DeepSeek、不触发冻结或补算。

## 4. 唯一业务 API

最终只保留：

- `GET /`
- `GET /api/v2/decisions/<strategy>/current`
- `GET /api/v2/decisions/<strategy>/history?date=YYYY-MM-DD`
- `GET /api/v2/decisions/<strategy>/dates`
- `GET /api/v2/status`
- `GET /api/v2/events`

`strategy` 只允许 `today`、`tomorrow`、`d25` 和 `long`。long 只有 current，没有冻结和历史。
API 和 SSE 共享同一决策身份、ETag 和单调事件序列；报价 overlay 必须匹配当前决策版本。

## 5. 不可破坏业务规则

- 固定融合公式、`ROUND_HALF_UP` 两位小数和固定向量 `83.40` 不变。
- `local_score` 已扣本地风险，融合时不得重复扣除。
- DeepSeek 自由文本不得直接决定分数、风险、动作或排名。
- DeepSeek 每日物理 HTTP 请求全局上限为 168，失败与重试同样计数。
- today 在 11:20 冻结，错过后不补算。
- tomorrow 和 d25 在 14:50 冻结；同日正式记录缺失时只允许既定 15:00 后恢复规则。
- long 只展示固定池当前行情，不评分、不冻结、不写历史、不调用 DeepSeek。
- 数据源或 DeepSeek 失败不能阻塞本地结果和只读 Web；最近有效数据必须显式降级保留。

## 6. 迁移原则

迁移不以保留旧输出为目标，而以 V2 自身的确定性、点时正确性、冻结不可变、资源有界和
失败降级为验收依据。顺序固定为：契约、数据平面、统一决策核心、独立运行时、tomorrow、
today、d25、long、统一 Web/API、删除旧链、最终发布。

每个批次先写失败契约和测试，再修改实现；完成独立 Review、完整适用门禁、一个提交和一次
推送后停止，等待下一次“继续”。

## 7. 完成定义

- `src/trader` 中不存在仍可到达的旧生产链、旧快照模型、旧 Web 或 shadow/cutover 实现。
- tests、配置、CLI、文档和 wheel 中不存在只服务旧链的内容。
- 四类视图全部由 V2 原生输入、索引、持久化、查询和事件流提供。
- 根页面和唯一业务 API 全部读取 V2。
- 架构、冻结、预算、SSE、三档桌面、打包和仓库外安装门禁全部通过。
