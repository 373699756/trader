## 结论

  当前评分系统的工程约束、冻结机制和风险门禁比较扎实，但“评分本身”仍属于人工权重驱动的启发式模型，不是针对未来净超额收益校准出来的预测模型。

  提高收益的最佳路线不是继续微调 22.22%/27.78% 这些权重，而是建立新的影子评分体系：

  > 点时特征 → 残差化因子 → 个股成本 → 预期净超额 → 严重亏损概率 → 受约束选股 → 样本外晋级

  现有生产评分、68/32 融合和冻结契约暂时不动。新模型只有通过历史样本外和前向影子门禁，才能另立批次替换生产配置。收益改善只能定义为“成本后样本外净超额
  提高且尾部风险不恶化”，不能保证未来盈利。

  加速路线不再等待 2027 年 P1 窗口。已经冻结的 `score_tomorrow_shadow_p1_v1` 不能改日期、补日或复用身份，
  但“不可修改”不等于“必须继续等待”：P1 保持只读审计记录，下一实施批次应以新的
  `score_tomorrow_historical_p2_v1` 身份复用现有 `score_h0_v1` 历史归档完成回顾性筛选；候选封存后再
  创建 `score_tomorrow_shadow_p2_v1`，从随后第一个已确认交易日开始约 20 个交易日的真实前向影子。
  最快可信路径是“历史验证 + 约 20 个交易日前向影子
  + 人工生产晋级”，不是再收集 40 个未来交易日充当所谓历史阶段。

  ## 论文证据给出的方向

  - 短期反转与较长期动量可以同时存在，不能把所有过去收益统一作为正向趋势。Jegadeesh 1990
    (https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1540-6261.1990.tb05110.x)

  - A 股研究显示，价值、风险和交易类异常相对稳定，而普通历史收益和质量因子的证据较弱；残差动量和残差反转更值得验证。A 股异常研究
    (https://pure.eur.nl/en/publications/anomalies-in-the-china-a-share-market/)

  - 中国市场确实存在日内时段之间的可预测性，但相关论文主要证明“前半小时/倒数第二个半小时预测最后半小时”，不能直接推导为次日收盘
    Alpha。中国日内动量研究 (https://ideas.repec.org/a/eee/ecmode/v76y2019icp319-329.html)

  - 动量风险会随市场状态变化，波动率管理可以显著减少动量崩溃。因此“稳定性”更适合作为条件暴露或风险门禁，而不是简单加分。Momentum Has Its Moments
    (https://ciencia.ucp.pt/en/publications/momentum-has-its-moments/)

  - 流动性既可能包含风险溢价，也代表交易冲击成本，不能简单把高成交额等同于高预期收益。Amihud 2002 (https://doi.org/10.1016/s1386-4181%2801%2900024-6)
  - 树模型的优势主要来自非线性交互；动量、流动性和波动率是重要信号，但这不代表深度模型一定适合当前样本规模。Gu、Kelly、Xiu
    (https://www.nber.org/papers/w25398)

  - 新建和维持仓位使用不同门槛，是降低换手成本的有效方法。交易成本研究 (https://doi.org/10.1093/rfs/hhv063)
  - 因子研究必须控制多重检验，普通的单次显著性不足以证明有效。Harvey、Liu、Zhu (https://www.nber.org/papers/w20592)

  ## 推荐的 Tomorrow 五个固定挑战者

  新研究只能预注册有限的五个本地挑战者，禁止无限增加因子。

  1. residual_reversal

     使用 1/3/5 日收益，扣除市场、板块、行业、规模和流动性影响；验证短期反转，不预设所有股票都应反向。

  2. residual_momentum

     使用 20–60 日收益，但跳过最近 3–5 日，并进行波动率缩放；避免把短期过热误认为中期动量。

  3. session_decomposition

     分开隔夜跳空、上午、下午、最后 30 分钟、收盘位置和尾盘量比。直接检验它们对下一交易日收盘的延续或反转，不沿用“尾盘上涨必然加分”的假设。

  4. cost_risk_adjusted

     新增 Amihud 价格冲击、成交容量、个股残差波动、下行半方差、极端收益和回撤恢复速度。容量只决定是否可交易，个股成本从预测收益中扣除。

  5. constrained_ensemble

     使用前四组特征建立两个固定模型：
      - 正则化线性/排序模型作为可解释控制组；
      - 浅层 LightGBM 作为非线性交互挑战者。

     限制树深、叶节点样本和特征集合，使用早停；不在同一窗口反复搜索超参数。

  DeepSeek 不计入这五个本地挑战者。它继续使用结构化事实和现有固定融合公式，但必须单独证明相对 local-only 的同日同股增量；不能证明时继续发布 local-
  only。src/trader/domain/recommendation/fusion.py:91

  ## 新评分的研究形态

  每只股票先输出具有业务含义的预测：

  gross_excess_i     = 预测相对基准超额收益
  estimated_cost_i   = 点差代理 + 冲击成本 + 换手成本
  net_excess_i       = gross_excess_i - estimated_cost_i
  loss_probability_i = 严重亏损概率
  uncertainty_i      = 模型分歧或预测区间
  research_utility_i = net_excess_i - λ * uncertainty_i

  处理原则：

  - loss_probability 用于风险上限和选股门禁，不用自由文本直接扣分。
  - 本地结构化风险仍然只扣一次，不能与模型风险重复扣除。
  - 0–100 分只是 research_utility 的稳定横截面投影，不再是未经校准的人工权重总和。
  - 只有预期净超额下界大于零的股票才进入正式池；允许返回空池。
  - Top6 在行业、板块和成本约束下最大化组合净效用，而不是简单逐股排序后贪心截断。

  ## 实施计划

  ### 批次 0：修复研究证据链

  - 定位 score_p0_v2 缺失计划日的原因。
  - 已错过的正式点时样本不得补写或用收盘数据替代。

  - 保存特征版本、训练窗口、随机种子、模型哈希和完整逐日预测。

  文档和机器契约中显式记录 P1 被 P2 替代，不能只改本计划后假装活动研究身份已经变化。

  ### 批次 6：P1 人工晋级（取消等待）
