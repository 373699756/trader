# V1、V2、V3、V5 模型收益优化计划

## 目标与边界

本计划聚焦现有四档算法，目标是提高成本后的荐股收益，同时控制回撤和严重亏损。优化是否有效，以独立样本外结果判断；模型训练成功、预测指标改善或人工生产授权均不代表收益验证通过。

本文件只保存研究方案，不维护实施状态、验证结果或未完成项。后续研究接续[工程台账](3_工程实施.md)阶段213，运行和下载欠项仍归281、292，不接管其它协作者的任务。

评分、选席和收益准入以[评分逻辑](1_评分逻辑.md)为准，训练和工件协议以[下载训练](4_下载训练.md)为准，运行和发布以[工程设计](2_工程设计.md)为准。本计划中的候选参数均为研究建议，不直接改变生产配置。

范围限定为V1、V2、V3、V5，不比较XGBoost，不引入新算法档位。DeepSeek增量研究继续暂缓。

## 1. 建立八个模型头的统一收益基线

四档各有Tomorrow、D25两个头，先分别建立基线，再比较改动前后结果。

以下为计划编写时的配置基线，实际执行须重新核对[训练配置](../config/training.json)并固定摘要：

| 档位 | 算法 | 特征回看范围 | 有效拟合日期 | 首要研究问题 |
| --- | --- | --- | --- | --- |
| V1 | LightGBM排序器＋独立Ridge收益门 | 251日 | 750日 | 排序器是否选对前六，收益门是否误拒 |
| V2 | LightGBM回归 | 251日 | 1000日 | 行业模型是否提供有效过滤 |
| V3 | Ridge回归 | 61日 | 750日 | 线性信号、系数及校准是否稳定 |
| V5 | TCN序列回归 | 61日构成60步序列 | 61日 | 短训练期是否限制泛化，行业覆盖为何较低 |

固定数据版本、评价日期、信号时股票总体、成本和六席规则；样本、模型、参数及日期身份在仓库外隔离副本中封存。不同模型覆盖不同时，同时报告共同覆盖上的配对结果和完整总体上的实际结果，不丢弃缺模型对象或通过缩小总体制造改善。

基线报告至少包含：

- 前六席成本后超额收益、空槽比例、换手、回撤和严重亏损。
- 模型覆盖率、缺模型行业及拒绝原因。
- Rank IC、NDCG@6、预测校准情况。
- 拟合截止日、模型年龄，以及分年、行业、板块和市场状态的表现。

同日股票放在同一日期分区，训练、早停、校准和评价隔离。当前V1的20日工程预测评价不能代替长期收益验证。

交付物：八头基线报告，明确每档最主要的收益损失来源。

## 2. 修查数据与预测之间的偏差

先检查可能让四档共同失效的输入和时间问题，不将待验证假设直接认定为缺陷。

| 检查项 | 处理方式 |
| --- | --- |
| 历史特征与在线特征一致性 | 逐字段核对时间、单位、复权、停牌和缺失语义 |
| 盘中累计量价与历史整日基线可比性 | 用相同时点历史基线作隔离对照，核验当时可见性 |
| 模型年龄 | 核对拟合截止日与在线评分日间隔，研究固定重训周期 |
| 行业覆盖不足 | 分开统计样本不足、校准退化、字段缺失和质量拒绝，不降低门槛制造覆盖 |
| 历史信息可见性 | 核对当时股票人口、行业、财务和公告的披露及生效时间 |

发现确定性错误先修正，再重新建立基线。缺少真实历史人口或分钟证据时，结论只限于日频代理；不以代理结果补签点时收益资格。滚动研究中，所有变换、校准和重训只能使用对应评分日前已成熟的资料和标签。

交付物：特征一致性、模型年龄及覆盖归因报告。

## 3. 保持算法类型，分别优化四档

每次只改变一个因素。第一轮每档最多保留三个预先登记的改进候选，不做参数笛卡尔积搜索；候选内容、日期、预算和停止条件在读取评价结果前固定。Tomorrow、D25分别得出结论。

| 档位 | 优化顺序 | 要验证的收益机制 |
| --- | --- | --- |
| V1 | 拆分排序器与Ridge收益门贡献；再调整排序器约束、训练窗口；最后研究少量新特征 | 排序是否选对前六，收益门是否误拒优质对象 |
| V2 | 检查行业模型稳定性；比较行业独立与共享拟合；再调整窗口、近期样本权重及树模型约束 | 模型过滤能否持续排除成本后弱机会 |
| V3 | 检查系数稳定性与相关特征；调整惩罚强度；再比较窗口及共享拟合 | 简单线性关系是否稳定，冗余特征是否放大噪声 |
| V5 | 研究训练日期跨度与覆盖；拆分序列、辅助特征贡献；最后调整训练预算和网络约束 | 量价序列是否提供额外预测价值，短训练期是否限制泛化 |

### V1：分开优化排序器与收益门

先固定排序器研究Ridge收益门，再固定收益门研究排序器，避免两个组件同时变化。排序器研究优先考察叶节点最小样本数、模型约束和训练日期跨度；Ridge研究重点是独立校准稳定性和成本门误拒。排名质量与成本后前六席收益同时评价。

### V2、V3：检验行业拟合与共享拟合

共享拟合继续分别使用LightGBM、Ridge，并控制行业、市场、板块和流动性等共同暴露。覆盖增加本身不算收益改善；需要证明共享信息提升预测或过滤质量。窗口、近期样本权重和正则化分别试验，不同步改变最终排序职责。

V3先做低成本诊断：检查系数跨窗口方向、幅度和预测贡献，删除特征须有样本外增删对照。保留简单模型作为研究基准，不为追求复杂度强行增加输入。

### V5：先研究日期跨度，再增加训练复杂度

优先比较61、120、250个有效拟合日候选，前提是历史和隔离分区足够。该窗口比较占用首轮候选预算，不额外叠加网络搜索。固定60步输入、网络和评价日期，只改变拟合区左边界；如行业资格随样本数变化，分别报告共同覆盖与完整总体结果。

训练行数很多可能主要来自相同的少数日期，需要单独判断日期跨度的价值。确认后再比较仅序列、仅辅助特征和两者结合，最后才研究训练轮数、宽度、dropout和权重衰减。耗时、峰值内存与质量一起报告，不通过减少覆盖或放宽准入取得表面改善。

交付物：每档候选对原基线的配对报告，包括失败结果及适用边界。

## 4. 研究特征与选席链的增量

模型参数研究后，再按特征组研究：

- 波动调整后的趋势与反转。
- 成交量、成交额变化及其与价格变化的关系。
- 跳空、日内振幅、收盘位置等价格结构。
- 市场、板块和行业状态。

每次只增加或删除一组，检查增量能否跨日期和市场状态保持。财务与公告特征须先具备历史披露时点证据。特征、样本和模型身份随定义变化独立绑定，不借其它档位补造输入或排名。

同时拆分模型门、本地分、动作门和风险门的收益贡献，研究纯规则、规则加模型门等预先定义的配对方案。明确模型门拒绝、排名靠后、动作拒绝和风险否决分别造成的损失。

生产仍保持V1/V5模型排序、V2/V3按local_score排序及原动作规则；固定六席、板块最多四席、不补位等约束沿用权威合同。若证据支持调整权重或门槛，再单独登记研究候选，不与模型变更混合评价，不通过放宽已知硬风险制造收益。

交付物：有效特征清单，以及各道门的风险收益贡献。

## 5. 统一筛选标准与独立验收

开发区采用按交易日滚动验证，同日股票保持同一分区，边界至少隔离5个交易日，并核对标签成熟期。调参、校准、独立确认和终端留出分开；多个候选的比较、区块依赖和统计校正按评分逻辑第12节执行，不看结果后更换口径。

| 维度 | 验收要求 |
| --- | --- |
| 收益 | 20bp、50bp完整往返成本下通过现有收益门；相对原方案的配对增量须有统计证据，报告置信区间 |
| 风险 | 严重亏损、回撤、换手和容量满足权威合同的不恶化要求 |
| 稳定性 | 分日期、年份、市场状态和行业报告，检查收益是否集中依赖少数异常样本 |
| 可实现性 | 报告覆盖、不可交易率、滑点及延迟退出压力；100bp仅作为压力情景 |
| 最终确认 | 完整方案固定后，只开启一次至少200日的未见终端留出；不复用已开启留出 |

NDCG、Rank IC改善仅为辅助证据。D25机会标签、六槽选股贡献和实际资金收益分别报告；未定义重叠持仓、资金占用及退出规则时，不把机会标签直接年化为资金收益。

未通过候选停止，保留原方案并在唯一工程台账记录原因；不得在终端留出上继续调参。

交付物：独立确认与终端留出报告，以及保留原方案或形成新候选的结论。

## 6. 前瞻观察与生产切换

通过历史验证的候选先进行前瞻观察，核对真实输入、模型年龄、名单、成本、拒绝原因及风险表现。观察方案与停止条件提前固定，历史通过、前瞻观察及人工生产授权分别记录。

完成后形成可审查的生产切换方案，再申请生产变更授权。四档各自按双头完整工件发布，不覆盖另一档；已有冻结和旧Shadow记录保持原身份，遵守15:00 first-wins，不重算或改写历史。发布与回退按工程设计执行。

交付物：前瞻观察报告、候选工件身份和生产切换方案。

## 执行顺序

统一基线与数据核查 → V3低成本诊断 → V1排序及收益门 → V2过滤 → V5训练跨度 → 特征增量 → 独立验收 → 前瞻观察与授权切换。

首批实施范围为“八头统一基线与收益损失归因”，后续实验由报告决定。已有研究能力优先复用，可复用诊断扩展现有scripts框架；不以本计划重复建设已交付能力，也不在本文件添加进度清单。
